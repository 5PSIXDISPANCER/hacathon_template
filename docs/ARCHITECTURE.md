# Архитектура решения

## Контекст

Система предназначена для передачи файлов между двумя устройствами через акустический канал (колонки и микрофон). Данные кодируются в звуковые волны, передаются по воздуху и декодируются на принимающей стороне.

## Компоненты

### 1. **UI слой** (`src/core/gui/ui.py`)
- Построен на базе `customtkinter`
- Две основные функции:
  - **Передача**: выбор файла, установка параметров (формат, частота, размер фрейма)
  - **Приём**: прослушивание микрофона и сборка полученных данных
- Статус-индикаторы прогресса
- Валидация формы перед отправкой

### 2. **Архивирование** (`src/core/archiver/compressor.py`)
- Класс `Compressor` для сжатия и распаковки файлов
- Использует `py7zr` с различными фильтрами:
  - Файлы < 10 КБ → BZIP2
  - Файлы ≥ 10 КБ → LZMA2 (16 МБ словарь)
- Методы: `compress()`, `decompress()`, `get_size()`

### 3. **Аудио-кодирование** (`src/core/audio/modem.py`)
- Реализует M-FSK модуляцию (Multi-Frequency Shift Keying)
- 4 частотных канала, каждый с 16 тональностями
- Параметры:
  - Частота дискретизации: 44.1 кГц
  - Длительность символа: 80 мс
  - Базовая частота: 500 Гц
  - Шаг между каналами: 400 Гц
- Защита по Риду-Соломону (16 символов коррекции ошибок)
- Методы: `generate_frame_signal()`, `encode_large_file()`, `decode_large_file_from_samples()`

### 4. **Аудио I/O** 
- **`receiver.py`** (на самом деле передача): `Stream()` — проигрывание звука через колонки
  - Поддерживает паузы между чанками
  - Использует `pyaudio` с форматом `paFloat32`
- **`transmitter.py`** (на самом деле приём): `listen()` — запись с микрофона
  - Таймауты: полная - 60 сек, молчание - 15 сек
  - Собирает чанки в порядке индексов

### 5. **Кодирование данных** (`src/core/ggwave/converter.py`)
- Обёртка над библиотекой `ggwave`
- Разбивает файл на чанки (по 80 байт в raw, 128 байт после base64)
- Формат чанка: `INDEX/TOTAL:base64data`
- Методы: `encode_file()`, `decode_chunk()`

### 6. **Утилиты** (`src/core/utils.py`)
- `write_config()` — сохранение конфигурации передачи
- `bytes_file()` — чтение файла в памяти
- `write_bytes()` — запись бинарных данных

## Основные технические решения

1. **Сжатие перед передачей**: Файл сжимается в .7z архив перед кодированием → уменьшение объёма данных и времени передачи

2. **Чанкирование**: Большой архив разбивается на мелкие куски (80 байт raw) → каждый кодируется в отдельное ggwave-сообщение

3. **Коррекция ошибок**: Каждый пакет в M-FSK защищен кодом Рида-Соломона → восстановление потерянных или повреждённых данных

4. **М-FSK модуляция**: Использование 4 параллельных частотных каналов с 16 тональностями на канал → высокая пропускная способность

5. **Синхронизация**: Preamble (преамбула) `0xDEADBEEF` в начале каждого пакета для синхронизации декодера

6. **Таймауты и переподключение**: Микрофон слушает до 60 сек ожидания первого чанка, затем 15 сек молчания → разумный баланс между надёжностью и UX

## Зависимости

- `pyaudio` — работа с аудио-устройствами
- `py7zr` — сжатие и распаковка
- `ggwave` — кодирование/декодирование в звук
- `reedsolo` — коррекция ошибок Рида-Соломона
- `numpy`, `scipy` — обработка сигналов
- `customtkinter` — GUI

## Безопасность и приватность

- Нет шифрования данных (если требуется, добавить `cryptography`)
- Передача незащищённая от перехвата
- Файл конфига (`src/data/config.py`) содержит чувствительные пути — рекомендуется не коммитить
- Нет аутентификации отправителя/получателя
