# Hackathon Audio File Transfer

🎵 **Передача файлов через звук** — инновационное решение для безопасного обмена данными между устройствами используя аудиосигналы.

Проект реализует M-FSK модем для кодирования файлов в аудиосигнал, их передачу и декодирование с использованием GUI, основанного на эстетике Dota 2.

## Основной функционал

- 🎧 **Отправка файлов** через звук в виде аудиосигнала
- 📥 **Получение файлов** через микрофон
- 🗜️ **Автоматическое сжатие** файлов (7z архивы)
- 🎨 **Современный GUI** на базе CustomTkinter
- 🛡️ **Коррекция ошибок** с использованием кодов Рида-Соломона
- 🔐 **Проверка целостности** файлов (SHA-256)

## Требования

- **Python**: 3.8 или выше
- **ОС**: Windows, Linux, macOS
- **Оборудование**: Микрофон и динамики/наушники
- **pip**: Менеджер пакетов Python

## Как использовать

### Отправка файла

1. Нажмите кнопку **"ОТПРАВИТЬ"** в главном меню
2. Выберите файл для отправки
3. Настройте параметры (частота, размер буфера, формат)
4. Нажмите **"ОТПРАВИТЬ"**
5. Включите запись на целевом устройстве
6. Аудиосигнал передаст ваш файл

### Получение файла

1. Нажмите кнопку **"ПРИНИМАТЬ"** в главном меню
2. Нажмите **"НАЧАТЬ ЗАПИСЬ"**
3. Включите воспроизведение звука на отправляющем устройстве
4. После завершения нажмите **"НАЗАД"**
5. Файл будет автоматически декодирован и сохранён

## Решение проблем

### Ошибка: ModuleNotFoundError

**Решение:**
1. Убедитесь, что виртуальное окружение активировано
2. Переустановите зависимости:
   ```bash
   pip install --upgrade pip
   pip install -r requirements.txt --force-reinstall
   ```

### Звук не воспроизводится / не записывается

**Решение:**
1. Проверьте уровни громкости системы
2. Убедитесь, что микрофон/динамики подключены
3. Переинициализируйте аудиоустройства:
   ```bash
   pip uninstall sounddevice pyaudio -y
   pip install sounddevice pyaudio
   ```

### Ошибка при установке scipy или numpy

**Решение:**
- Обновите pip и setuptools:
  ```bash
  pip install --upgrade pip setuptools wheel
  ```
- Затем переустановите зависимости

### Permission denied (на Linux/macOS)

**Решение:**
```bash
chmod +x src/main.py
```
